# Relay memory

Open this folder as a vault in Obsidian. Each memory is a Markdown note. Use the folders below for memories that Relay can find and edit.

| Folder | What belongs here |
| --- | --- |
| Inbox | Facts waiting to be organized |
| Preferences | How you like things done |
| People | People and relationships |
| Projects | Project details and decisions |
| Routines | Recurring habits and procedures |
| Reference | Information you want to look up later |
| Handoffs | Conversation checkpoints saved and resumed by topic |

You can edit notes directly, link them with `[[wikilinks]]`, and add Obsidian properties. Keep memory notes directly inside a category folder. Move a note between these folders to recategorize it. For predictable lookup, give each note a distinct name.

Relay uses this vault by default. Set `RELAY_MCP_VAULT_DIR` to select another folder. If only `RELAY_MCP_DATA_DIR` is set, Relay uses its `vault` subfolder.
